6. Maps with leaflet

leaflet() package allows you to make basic interactive maps using just a couple lines of code

addTiles() function without arguments will add base tiles to your map from OpenStreetMap

addMarkers() will add a marker at each location specified by the latitude and longitude arguments

leaflet(locations) %>%
    addTiles() %>%
    addMarkers(
        lng = ~ longitude,
        lat = ~ latitude,
        popup = ~ restore_loc
    )
leaflet(locations) %>%
    addProviderTiles(providers$Esri.WorldTopoMap) %>%
    addCircleMarkers(
        lng = ~ longitude,
        lat = ~ latitude,
        popup = ~ restore_loc,
        radius = 5,
        # set fill properties
        fillColor = "salmon",
        fillOpacity = 1,
        # set stroke properties
        stroke = TRUE,
        weight = 0.5,
        color = "white",
        opacity = 1)
leaflet(locations) %>%
    addProviderTiles(providers$Esri.WorldImagery) %>%

Discussion

The stacked bar plot helps show both how many visits each restoration site received and which types of visitors were most common. Sites like Prospect and Grizzly Bay have the longest bars, so they had the highest total number of visits during the study period, while places such as Sherman Island and Wildlands have much shorter bars and therefore much lower use. Within each bar, the different colors show how visits are divided among boats, bank anglers, scientists, and cars, which makes it easier to compare visitor patterns between locations. For example, some sites have large segments from boat visitors, while other sites show a bigger contribution from cars or bank anglers. This suggests that not all restoration areas are used in the same way, even if their total number of visits is similar.

The interactive map of restoration locations adds geographic context by showing where these sites are located in the Delta. When looking at the map together with the bar plot, it becomes easier to connect high‑use and low‑use sites with their positions on the landscape and to think about how access or local conditions might influence visitor activity.X
